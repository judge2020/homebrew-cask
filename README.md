# Homebrew casks

## Install DiscreteScroll

```sh
brew install --cask judge2020/cask/discrete-scroll
```

DiscreteScroll removes scroll-wheel acceleration. It requires macOS 12 or later and runs on Apple silicon and Intel Macs. On first launch, grant DiscreteScroll access in System Settings under Privacy & Security > Accessibility.

The release is signed with the Corporate Clash Developer ID and notarized by Apple. See the [upstream source at commit `eb86e06`](https://github.com/emreyolcu/discrete-scroll/tree/eb86e06339aad92d96d61fa780c54466e21de2f4) and the [MIT License](LICENSE).
